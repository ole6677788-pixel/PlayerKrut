Компактный плавающий мини-плеер для Windows 10/11: показывает текущий трек из системной Windows Media Session.

## Установка
1. Установи Node.js LTS: https://nodejs.org/
2. Скачай ZIP: https://github.com/ole6677788-pixel/PlayerKrut/archive/refs/heads/main.zip
3. Распакуй архив и открой папку проекта.
4. В адресной строке Проводника введи `cmd` и нажми Enter.
5. Выполни:
   ```bat
   npm install
   npm start
   ```

## Важно
Обложка и метаданные зависят от Windows Media Session; некоторые источники не поддерживают перемотку.

## Технологии
Electron, HTML/CSS/JavaScript, PowerShell, Windows Media Control API.
