# PlayerKrut 🎧

Компактный плавающий мини-плеер для Windows: показывает название трека, исполнителя и состояние воспроизведения из Windows Media Session.

## Возможности
- Компактное окно поверх других окон.
- Неоново-розовое оформление, анимированная обложка и эквалайзер.
- Автообновление примерно каждые 2,5 секунды.
- Обновление вручную, закрепление поверх окон, сворачивание и закрытие.
- Работает локально через Windows Media Control API.

Важно: отображаются только треки, которые музыкальное приложение или браузер передаёт в Windows. Управление воспроизведением пока не реализовано.

## Установка на Windows 10/11
1. Установи Node.js LTS: https://nodejs.org/
2. На GitHub открой репозиторий PlayerKrut, нажми **Code → Download ZIP** и распакуй архив.
3. Открой папку проекта в Проводнике.
4. Нажми адресную строку папки, введи `cmd` и нажми Enter.
5. Выполни команды по очереди:
   ```bat
   npm install
   npm start
   ```
6. Включи музыку в поддерживаемом приложении — мини-плеер должен показать трек.

## Повторный запуск
Открой терминал в папке проекта и выполни `npm start`.

## Если музыка не отображается
- Убедись, что трек играет, а не только открыт экран музыкального сервиса.
- Проверь, появляется ли трек в системном медиаконтроле Windows.
- Не каждое приложение публикует метаданные для Windows Media Session.
- Если команда `npm` не найдена, установи Node.js LTS и заново открой терминал.

## Технологии
Electron, HTML/CSS/JavaScript, PowerShell и Windows Media Control API.
