# PlayerKrut 🎧

**Версия 1.7.0** — компактный мини-плеер в стиле Яндекс Музыки: обложка по центру, мягкий размытый фон из её цветов и крупные минималистичные кнопки управления.

Компактный плавающий мини-плеер для Windows 10/11: показывает текущий трек из системной Windows Media Session.

## Что нового в 1.7.0
- Обновлён интерфейс по мотивам Яндекс Музыки: обложка по центру, мягкий цветной фон и минималистичное управление.
- Крупнее центральная кнопка воспроизведения, более аккуратная шкала трека и улучшенная читаемость метаданных.
- Сохранены акцент `#D98383`, изменение размера окна и просмотр списка изменений.

## Что нового в 1.5.0
- Обложка текущего трека используется как размытый фон окна.
- Нажатие на номер версии открывает список изменений.
- Кнопки `−` и `+` изменяют размер окна; минимальный размер уменьшен.
- Время трека плавно обновляется между запросами к Windows.

## Что нового в 1.4.0
- Переработан дизайн: тёмная минималистичная панель, квадратная обложка, крупное название трека и мягкий акцентный цвет `#D98383`.
- Добавлены кнопки `−` и `+`, чтобы надёжно уменьшать и увеличивать окно; также оставлено изменение размера за угол.
- Время проигрывания обновляется плавно между запросами к Windows Media Session.

## Что нового в 1.2.0
- Полностью обновлённый центрированный интерфейс в стиле neon/glass.
- Большая анимированная светящаяся сфера, движущиеся цветовые ореолы, кольца и частицы.
- Анимация усиливается во время воспроизведения; это визуальная анимация, а не измерение реальных басов.
- Название трека, исполнитель и альбом, если источник передаёт эти данные Windows.
- Кнопки предыдущего трека, воспроизведения/паузы и следующего, плюс ползунок перемотки и время трека при поддержке источника.
- Изменение размера перетаскиванием за угол справа снизу и кнопками масштаба.
- Открытие приложения-источника, закрепление поверх окон, сворачивание и закрытие.
- Версия отображается прямо в окне.

## Установка
1. Установи Node.js LTS: https://nodejs.org/
2. Скачай ZIP: https://github.com/ole6677788-pixel/PlayerKrut/archive/refs/heads/main.zip
3. Распакуй архив и открой папку проекта.
4. В адресной строке Проводника введи `cmd` и нажми Enter.
5. Выполни:
   ```bat
   npm install
   npm start
   ```

## Важно
Обложка и метаданные зависят от Windows Media Session; некоторые источники не поддерживают перемотку. При ошибке чтения плеер показывает сообщение об ошибке. Если название не появляется, проверь системный медиаконтрол Windows: не все сервисы и браузерные вкладки передают данные одинаково.

## Технологии
Electron, HTML/CSS/JavaScript, PowerShell, Windows Media Control API.
