# PlayerKrut 🎧

**Версия 1.16.0** — UI полностью по референсу (пауза / воспроизведение), жидкий ARGB-фон в стиле Яндекс.Музыки, мягкие лучи, анимации кнопок, избранное, громкость, возврат в приложение, версия снизу справа.

**Версия 1.15.0** — ARGB жидкое пятно как в Яндекс.Музыке, чистый UI по референсу, фикс обложки/названия/исполнителя.

Компактный плавающий мини-плеер для Windows 10/11: показывает текущий трек из системной Windows Media Session.

## Что умеет
- Два режима UI: большая кнопка Play (пауза) и обложка + контролы (воспроизведение)
- Жидкий неоновый фон с лучами, реагирует на бас
- Обложка, название и исполнитель
- Перемотка по шкале названия
- Prev / Next / Play-Pause
- Добавление в избранное (визуально + в приложении музыки)
- Возврат в приложение-источник (снизу слева)
- Версия с changelog (снизу справа и сверху)
- Поверх всех окон (включая игры)
- Полностью масштабируемое окно
- Плавные анимации нажатий

## Установка
1. Установи Node.js LTS: https://nodejs.org/
2. Скачай ZIP: https://github.com/ole6677788-pixel/PlayerKrut/archive/refs/heads/main.zip
3. Распакуй архив и открой папку проекта.
4. В адресной строке Проводника введи `cmd` и нажми Enter.
5. Выполни:
   ```bat
   npm install
   npm start
   ```

## Важно
Обложка и метаданные зависят от Windows Media Session; некоторые источники не поддерживают перемотку.

## Технологии
Electron, HTML/CSS/JavaScript, PowerShell, Windows Media Control API.
