# PlayerKrut 🎧

**Версия 1.11.0** — обновлена жидкая ARGB-анимация, плашка названия стала основной шкалой времени, исправлено обновление обложки и метаданных, улучшено масштабирование окна.

**Версия 1.10.0** — адаптивная компоновка: обложка, название трека и исполнитель корректнее масштабируются при изменении размера окна. Убраны декоративные полоски эквалайзера.

**Версия 1.9.0** — компактный мини-плеер в стиле Яндекс Музыки: обложка по центру, мягкий размытый фон и минималистичное управление.

Компактный плавающий мини-плеер для Windows 10/11: показывает текущий трек из системной Windows Media Session.

## Что нового в 1.11.0

- Переработан жидкий фон: мягкие розово-малиновые и фиолетовые формы вместо резкого RGB-эффекта.
- Плашка с названием трека теперь является основной шкалой времени: прогресс заполняет её по ширине, перемотка работает нажатием и перетаскиванием.
- Удалён дублирующий нижний ползунок времени.
- Исправлена ошибка обращения к отсутствующему элементу прогресса, которая могла прерывать обновление обложки и метаданных.
- Упрощены и объединены CSS-правила для стабильного масштабирования при разных размерах окна.
- Список изменений и номер версии синхронизированы с 1.11.0.

## Установка
1. Установи Node.js LTS: https://nodejs.org/
2. Скачай ZIP: https://github.com/ole6677788-pixel/PlayerKrut/archive/refs/heads/main.zip
3. Распакуй архив и открой папку проекта.
4. В адресной строке Проводника введи `cmd` и нажми Enter.
5. Выполни:
   ```bat
   npm install
   npm start
   ```

## Важно
Обложка и метаданные зависят от Windows Media Session; некоторые источники не поддерживают перемотку. При ошибке чтения плеер показывает сообщение об ошибке. Если название не появляется, проверь системный медиаконтрол Windows: не все сервисы и браузерные вкладки передают данные одинаково.

## Технологии
Electron, HTML/CSS/JavaScript, PowerShell, Windows Media Control API.
